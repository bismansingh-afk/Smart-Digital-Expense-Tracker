# Smart-Digital-Expense-Tracker
Smart Digital Expense Tracker with Budget Prediction

Project Information

* University: COER University
* Course: Bachelor of Computer Applications (BCA)
* Lab Sheet: 09
* Language: C++

Project Description

Smart Digital Expense Tracker is a console-based C++ application that helps users manage their daily expenses and budgets.

Features

1. User Registration and Login
2. Add and View Expenses
3. Category-wise Expense Report
4. Monthly Expense Report
5. Set Monthly Budget
6. Budget Warning System
7. Expense Prediction
8. Search Expenses
9. Delete Expenses
10. File Handling for Data Storage

Concepts Used

* Structures
* Arrays
* Functions
* Loops and Conditional Statements
* Strings
* File Handling
* Searching and Sorting

How to Run

Compile using a C++ compiler:

g++ main.cpp -o expense
